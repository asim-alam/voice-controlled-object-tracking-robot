# Project gallery

`actual-robot-hero.png` is the active README hero. It is an AI-assisted cleanup
derived from multiple photographs of the real VROD prototype. The background,
phone interface, people, and desk clutter were removed while the real robot's
structure and visible components were used as identity references.

The two unmodified robot-only source images are stored under `references/`:

- `actual-robot-front-original.jpeg`
- `actual-robot-top-original.jpeg`

The earlier hypothetical images are archived under `concepts/` and are no
longer referenced by the root README. They are retained only as design-history
assets and may be omitted from the eventual Git commit.

Remove location or device metadata from source photographs before publishing if
privacy matters.
