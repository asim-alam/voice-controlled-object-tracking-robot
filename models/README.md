# Edge Impulse model

`ei-bag-detection-arduino-1.0.1.zip` is the exported Arduino library used by
the vision controller. Install it in Arduino IDE with **Sketch > Include
Library > Add .ZIP Library**, then restart the IDE if the
`Bag_detection_inferencing.h` include is not found.

The archive contains the generated model plus Edge Impulse SDK and third-party
license files. Keep those files with the model when redistributing it.
